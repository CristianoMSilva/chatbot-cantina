Política de Privacidade

Cantina Tia Eleusa · Última atualização: 01/11/2026

Esta política explica quais dados a Cantina Tia Eleusa coleta, para que usa e quais são os seus direitos, de acordo com a Lei Geral de Proteção de Dados (LGPD, Lei nº 13.709/2018).

1. Quem é a responsável pelos dados

Cantina Tia Eleusa, localizada no Colégio Athenas, Rua Inconfidência, 4-73, Bauru (SP), CEP 17010-070.
Contato: WhatsApp (14) 99652-2852.

2. Quais dados coletamos

Do responsável (pai, mãe ou responsável legal):

  • Nome
  • Número de WhatsApp

Do aluno:

  • Nome
  • Série e turno (manhã ou tarde)
  • Autorização para compras a prazo ("fiado"), definida pelo responsável
  • Saldo de créditos

Das movimentações: cada crédito ou consumo registra o aluno, o tipo, a origem, o valor, a descrição e a data.

Das conversas no WhatsApp: as mensagens trocadas com o nosso atendimento, inclusive o atendimento automático.

Não coletamos CPF, data de nascimento nem endereço dos alunos.

3. Para que usamos os dados

  • Identificar o aluno no momento da compra
  • Controlar créditos, consumos e saldo
  • Informar saldo e extrato ao responsável pelo WhatsApp
  • Enviar avisos sobre a conta do aluno (por exemplo, saldo baixo)

Os dados não são usados para nenhuma outra finalidade.

4. Dados de crianças e adolescentes

Os dados dos alunos são tratados com o consentimento do responsável, dado no momento do cadastro, e sempre no melhor interesse da criança ou do adolescente, como prevê o artigo 14 da LGPD. O responsável pode revogar esse consentimento a qualquer momento.

5. Com quem compartilhamos

Não vendemos nem cedemos dados a terceiros. Os dados passam apenas pelos serviços necessários para o sistema funcionar:

  • WhatsApp (Meta): para o envio e o recebimento de mensagens
  • Provedor de hospedagem: onde o sistema e o banco de dados ficam armazenados

6. Armazenamento e segurança

Os dados ficam em servidor com conexão segura (HTTPS), e o painel de administração tem acesso restrito por login. Os dados são mantidos enquanto o aluno utilizar a cantina. Depois disso, ou a pedido do responsável, são excluídos, exceto quando a lei exigir a guarda de algum registro.

7. Seus direitos

O responsável pode, a qualquer momento:

  • Saber quais dados temos
  • Corrigir dados incompletos ou errados
  • Pedir a exclusão dos dados
  • Revogar o consentimento

Para isso, basta falar com a gente pelo WhatsApp (14) 99652-2852.
